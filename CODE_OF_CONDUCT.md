# Code of Conduct

## Our pledge

We want Paperback to be a friendly, harassment-free project for everyone, regardless of age,
body size, disability, ethnicity, gender identity or expression, level of experience,
nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and constructive; critique code and ideas, not people.
- Assume good faith; ask questions before attributing bad intent.
- Accept feedback gracefully and give it kindly.
- Keep discussions on topic and welcoming to newcomers.

## Unacceptable behaviour

- Harassment, insults, threats, or discriminatory jokes and language.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing others' private information without permission.
- Sustained disruption of discussions, issues or pull requests.

## Scope

This applies in all project spaces — issues, pull requests, discussions, commit comments — and
when representing the project elsewhere.

## Enforcement

Maintainers may remove comments, close threads, or block contributors who violate this code.
Report problems privately to the maintainers (open a GitHub issue asking for a private channel
if you don't have a contact). Reports are handled discreetly and in good faith.
